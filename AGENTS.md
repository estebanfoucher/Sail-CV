# Sail-CV

Stereo-vision sail tracking: two RTSP cameras + a Jetson Nano, with a 3D
reconstruction/viewer pipeline.

## Hardware & network

Before doing any work involving the cameras, Jetson, or network connectivity,
read [`docs/hardware setup and specs.md`](docs/hardware%20setup%20and%20specs.md).
It documents the device IPs, RTSP/SSH endpoints, and how to verify the Mac is
wired to the correct subnet.
